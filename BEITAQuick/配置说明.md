# BEITAQuick 安装器配置说明

## 目录结构

安装器需要在编译后的可执行文件同级目录下配置以下结构：

```
App/
├── BEITAQuick.exe
├── config.ini (必需 - 应用程序名称)
├── LICENSE.txt (可选)
├── CONTENT_1/
│   ├── config.ini
│   └── CONTENT/
│       └── FolderA/
│           └── (要复制的文件)
├── CONTENT_2/
│   ├── config.ini
│   └── CONTENT/
│       └── FolderB/
│           └── (要复制的文件)
└── CONTENT_N/
    ├── config.ini
    └── CONTENT/
        └── FolderX/
            └── (要复制的文件)
```

## 配置文件说明

### 根目录 config.ini (必需)

位于应用程序根目录的 `config.ini` 文件用于配置应用程序名称。

**文件格式：** 纯文本文件，只包含一行内容

**示例内容：**
```
我的应用程序
```

或者：
```
MyApplication 2.0
```

此名称将显示在：
- 窗口标题栏："我的应用程序 - 安装向导"
- 欢迎页面："欢迎安装 我的应用程序"
- 欢迎消息："此向导将引导您完成 我的应用程序 的安装过程。"
- 完成页面："我的应用程序 已成功安装！"

### CONTENT_N/config.ini

每个 `CONTENT_N` 目录下的 `config.ini` 文件包含目标安装路径。

**文件格式：** 纯文本文件，只包含一行内容（目标路径）

**示例内容：**
```
C:\Program Files\MyApp
```

或者：
```
C:\Users\Public\Documents\MyApp
```

**注意事项：**
- 不要在路径末尾添加反斜杠 `\`
- 支持中文路径
- 如果目标目录不存在，安装器会自动创建

### LICENSE.txt (可选)

如果在根目录下存在 `LICENSE.txt` 文件，安装器会在安装前显示许可协议页面，用户必须接受协议才能继续安装。

**文件格式：** 纯文本文件，可以包含多行内容

**示例内容：**
```
软件许可协议

版权所有 (C) 2026

本软件按"原样"提供...
```

## 安装逻辑

1. 安装器会扫描所有 `CONTENT_*` 目录
2. 读取每个目录下的 `config.ini` 获取目标路径
3. 将 `CONTENT/` 下的所有文件夹复制到目标路径

**示例：**

如果配置如下：
- `CONTENT_1/config.ini` 内容为：`C:\Program Files\MyApp`
- `CONTENT_1/CONTENT/` 下有 `FolderA` 和 `FolderB`

则安装后：
- `FolderA` 会被复制到 `C:\Program Files\MyApp\FolderA`
- `FolderB` 会被复制到 `C:\Program Files\MyApp\FolderB`

## 界面特性

- **Aero 风格设计**：现代化的 Windows Aero 风格界面
- **侧边图片**：左侧显示 656x1632 分辨率的品牌图片
- **多步骤向导**：
  1. 欢迎页面
  2. 许可协议页面（如果有 LICENSE.txt）
  3. **自定义安装路径页面**（新增）
  4. 安装进度页面
  5. 完成页面
- **实时进度**：显示当前安装进度和正在处理的文件
- **路径自定义**：用户可以为每个组件单独选择安装位置
  - 默认显示 config.ini 中配置的路径
  - 支持手动输入路径
  - 支持通过"浏览"按钮选择文件夹
  - 实时显示最终安装位置预览

## 编译和部署

1. 使用 Visual Studio 打开项目
2. 编译为 Release 版本
3. 在输出目录创建上述目录结构
4. 配置 `config.ini` 和内容文件
5. 可选：添加 `LICENSE.txt`
6. 分发整个目录给用户
